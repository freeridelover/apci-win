# apci-win-android
ACPI - Automated Portable Content Interface
A Smart and user friendly Bluetooth transmitter and receiver. 
How to use:
-Download both the Windows and Android versions
-Transfer the .APK file to your android device that has at least Android 4.4.4 and install it
-Turn on both devices bluetooth (duh)
-Select your device in the selection menu in the Windows application
-Turn on the transmitter on the android app
-Select the file to transmit
-Click 'Send file"
